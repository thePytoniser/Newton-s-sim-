# Newton-s-sim-
I created a simulation of Newton's law

# The software :
To run it, you have to use an IDE that run Python
For exemple : Pycharm Community Edition, Thonny or pyzo

# The modules:
Make sure that you have install the module pygame.
If you haven't installed it yet, find the console of your IDE and type :
`pip install pygame` 

# Now ... run it
Finally, just run the `main.py` file and it must run
